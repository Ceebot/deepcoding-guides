## Заметки

- Opencode + DeepseekV4дешевая, но мощная связка (Речь про возможность комбинирования инструментов для получения наилучшего результата: умная модель планирует, слабая модель выполняет, плюсы: экономия токенов)
- Obsidian (работа с AI)
- Создание новых своих скилов
- Использование MCP  (Context7, Playwright)
- Использование скилов (Brainstorming, проектные скиллы)
- Субагенты (worker, planner. tester)
- Использование правил - добавление своих правил
- Безопасность - способы её контроля - специализированный агент (OpenAI) который проверят безопасаность.
- Работа с разными форматами данных - картинки, pdf, docx, excel (в claude code и др)
- Контроль выходной. Различные формы review, с применением авто-тестов, линтинга, статического анализа. Крос-агентами. Или скилками для review
- Связка субагентов - скилл, описывающий workflow по порядковому вызову субагентов для реализации целых фичей
- Harness engeneering - создание обявзок, чтобы агентские системы в рамках правил, скилов, mcp, структуры, документации - могли делать работу автономно и кчественно.
- Autoresearch - циклы оптимизации до достижения необходимого результата (агент работает в цикле пока не достигнет резульата)
- Планирование задачи - встроенные инструменты/общение с агентом со скиллом brainstorming
- task-logs.md - файл с короткими логами прошлых изменений в проекте (данный файл содержит информацию о том, что было сделано для контекста ИИ, так же должна быть инструкция/скилл по обновлению этого файла, например в AGENTS.md|CLAUDE.md|CURSOR.md)
- Агент debug в Cursor - отслеживание ошибок
- AGENTS.md|CLAUDE.md|CURSOR.md - основной файл правил проекта с картографией документаций проекта
- Обратная совместимость файлов для ИИ между разными инструментами
- Разведка перед началом работы/init
