# Технические решения

Фиксируем выборы, чтобы агенты не переизобретали стек на каждом шаге.

| Решение | Выбор | Обоснование |
|---------|-------|-------------|
| СУБД | SQLite 3 | Локально, без сервера, соответствует `*.db` в `.gitignore`, ТЗ §10 |
| Файл БД | `data/telecom.db` | Отдельно от исходников, каталог `data/` в `.gitignore` по маске `*.db` |
| Миграции | SQL-файлы + `migration_history` | ТЗ §4, §5; без внешних ORM |
| Автоматизация | `Makefile` → `scripts/manage_db.py` | ТЗ §7, todo блок 5 |
| Язык скриптов | Python 3.11+ (stdlib: `sqlite3`, `argparse`, `pathlib`) | Без лишних зависимостей |
| Git | Отдельный репозиторий в `project/` | Todo блок 1; изоляция демо-проекта |
| Именование | `snake_case` для таблиц и колонок | ТЗ §10 |
