# Этап 13. Безопасность

[← К roadmap](../README.md)

Цель: не дать ИИ сломать приватность, доступы и production.

## Основные риски

- Утечка секретов в prompt или git.
- Случайное удаление данных.
- Небезопасные SQL-запросы.
- XSS, SSRF, command injection.
- Слишком широкие права для MCP.
- Автоматический запуск опасных команд.
- Зависимости с уязвимостями.

## Правила

- Не отправлять токены, пароли, ключи.
- Использовать dev/stage окружение.
- Разделять read-only и write tools.
- Просить агента объяснять опасные команды.
- Проверять зависимости.
- Добавить security-review prompt или отдельного агента.

## Prompt для security review

```md
Проверь изменения как security reviewer.
Ищи: secrets, injection, auth bypass, unsafe file access, dangerous shell commands.
Не комментируй стиль.
Для каждой проблемы дай severity и конкретный фикс.
```

## Домашнее задание

- Взять любую AI-правку.
- Попросить security review.
- Проверить, нет ли секретов и небезопасных команд.
- Добавить одно security-правило в `AGENTS.md`.
