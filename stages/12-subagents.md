# Этап 12. Субагенты и параллельная работа

[← К roadmap](../README.md)

Цель: делить сложную задачу между специализированными агентами.

## Роли субагентов

- Planner - изучает задачу и делает план.
- Explorer - исследует проект.
- Worker - реализует код.
- Tester - пишет и запускает тесты.
- Reviewer - ищет баги.
- Security - проверяет секреты, инъекции, доступы.
- Docs - обновляет документацию.

## Пример workflow

```md
Planner: составь план и риски.
Explorer: найди похожие реализации.
Worker: сделай минимальную реализацию.
Tester: добавь тесты и запусти проверки.
Reviewer: проверь diff на баги.
```

## Когда запускать параллельно

- Нужно быстро исследовать несколько частей проекта.
- Есть несколько вариантов решения.
- Нужно сравнить ответы разных моделей.
- Нужно review от независимого агента.

## Домашнее задание

- Одну задачу поручить двум агентам: один планирует, другой ищет похожий код.
- Сравнить результаты.
- На основе двух ответов составить финальный план.
