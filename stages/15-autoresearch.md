# Этап 15. Autoresearch и автономные циклы

[← К roadmap](../README.md)

Цель: научить агента работать в цикле до проверяемого результата.

## Где это полезно

- "Исправляй тесты, пока они не пройдут".
- "Оптимизируй запрос, пока p95 не станет меньше 300ms".
- "Проверяй UI в браузере, пока не совпадет с макетом".
- "Ищи причину бага через гипотезы и логи".

## Важное ограничение

Автономность нужна только там, где есть четкий критерий успеха.

Плохо:

```md
Сделай красиво.
```

Хорошо:

```md
Итерируй CSS, пока кнопка не будет визуально совпадать с макетом.
После каждой правки делай screenshot и сравнивай отступы.
Остановись после 5 итераций или когда результат совпал.
```

## Домашнее задание

- Выбрать задачу с проверяемым результатом.
- Задать лимит итераций.
- Попросить агента вести короткий лог попыток.
- После окончания оценить, где он ошибался.
