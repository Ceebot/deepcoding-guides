# Этап 8. Тесты, ревью и контроль качества

[← К roadmap](../README.md)

Цель: не верить ИИ на слово.

## Контрольный выход

После AI-правок нужно проверять:

- Tests: unit, integration, e2e.
- Lint / format.
- Typecheck.
- Static analysis.
- Security scan.
- Manual QA.
- Code review.
- Cross-agent review: другой агент проверяет решение.

## Prompt для ревью

```md
Проведи code review текущих изменений.
Ищи только реальные баги, регрессии, проблемы безопасности и пропущенные тесты.
Не предлагай стилистический рефакторинг без причины.
Ответ: severity, файл, проблема, как исправить.
```

## Prompt для тестов

```md
Посмотри текущую реализацию и добавь недостающие тесты.
Не меняй production-код.
Покрой happy path, edge cases и ошибочные входные данные.
```

## Домашнее задание

- Взять AI-сгенерированную правку.
- Запустить тесты и линтер.
- Попросить второго агента сделать review.
- Исправить минимум одну найденную проблему.
