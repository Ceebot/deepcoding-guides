# Этап 10. MCP и внешние инструменты

[← К roadmap](../README.md)

Цель: подключить ИИ к реальным источникам данных и инструментам.

MCP - это стандартный способ дать агенту инструменты: документацию, браузер, базу данных, Postman, Sentry, Slack, GitHub, файловую систему.

## Полезные MCP

- Context7 - свежая документация по библиотекам.
- Playwright / Browser - проверка UI в браузере.
- Postman - работа с API коллекциями.
- GitHub - issue, PR, review.
- Sentry / Datadog - ошибки и логи.
- Database MCP - запросы к dev/stage базе.

## Когда использовать MCP

- Нужно проверить актуальную документацию.
- Нужно протестировать UI.
- Нужно посмотреть ошибку в логах.
- Нужно прочитать issue или PR.
- Нужно дернуть API.

## Пример

```md
Используй документацию React Query через MCP.
Проверь, как правильно инвалидировать query после mutation.
Потом предложи правку в нашем коде.
```
