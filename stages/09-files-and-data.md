# Этап 9. Работа с файлами и разными форматами данных

[← К roadmap](../README.md)

Цель: использовать ИИ не только для кода.

## Что можно отдавать ИИ

- Скриншоты ошибок.
- Макеты UI.
- PDF с требованиями.
- DOCX с ТЗ.
- Excel/CSV с данными.
- Логи.
- SQL dumps без секретов.
- Изображения для visual debug.

## Примеры

```md
Проанализируй этот CSV.
Найди подозрительные дубли заказов.
Сначала опиши правила проверки, потом покажи найденные строки.
```

```md
По скриншоту видно, что кнопка уехала вниз.
Найди компонент, который отвечает за этот экран, и предложи CSS-фикс.
```

## Домашнее задание
