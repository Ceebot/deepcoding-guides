# Этап 7. Реализация фич с агентом

[← К roadmap](../README.md)

Цель: научиться безопасно делегировать код.

## Правила реализации

- Один prompt - один понятный шаг.
- Не смешивать фичу, рефакторинг и форматирование.
- Просить агент использовать существующие паттерны.
- После изменения смотреть diff.
- Не принимать код, который не понимаешь.

## Хороший workflow

```md
1. Найди похожую реализацию.
2. Предложи минимальный план.
3. Реализуй только backend-часть.
4. Добавь тесты.
5. Запусти тесты.
6. Сделай self-review diff.
```

## Пример задачи

```md
Добавь фильтр заказов по статусу.
Используй текущий стиль фильтров.
Не меняй API ответа.
Добавь тест на новый query param.
После изменений запусти тесты для orders.
```

## Домашнее задание

- Реализовать маленькую фичу через агента.
- Перед каждым шагом писать, что именно агент должен сделать.
- После каждого шага читать diff и просить объяснить изменения.
