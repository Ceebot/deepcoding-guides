# Этап 7. Реализация фич с агентом

[← К roadmap](../README.md)

Цель: научиться превращать план в рабочий код, не отдавая агенту контроль над архитектурой.

На этом этапе ИИ работает как исполнитель. Вы уже знаете, что нужно сделать, и ведете агента по шагам: даете контекст, ограничения, план и проверяете результат после каждого изменения.

## Правила реализации

- Один prompt - один понятный шаг.
- Не просить агента "сделать все сразу".
- Не смешивать фичу, рефакторинг и форматирование.
- Просить агент использовать существующие паттерны.
- Давать агенту только нужный контекст: описание проекта, ограничения, документацию и текущий шаг плана.
- После изменения смотреть diff.
- Не принимать код, который не понимаешь.
- Reject, если агент удаляет важное, меняет лишнее или добавляет отсебятину.

## Хороший workflow

```md
1. Открой todo.md или план задачи.
2. Выбери один небольшой пункт.
3. Дай агенту контекст и строгие ограничения.
4. Попроси реализовать только этот пункт.
5. Проверь diff и объяснение изменений.
6. Прими, исправь или отклони правку.
7. Только потом переходи к следующему пункту.
```

## Пример задачи

```md
Реализуй только блок 2 из todo.md.
Используй текущие паттерны проекта.
Не меняй публичный API и соседнюю логику.
Не делай рефакторинг вне задачи.
После изменений кратко объясни diff.
```

## Домашнее задание

- Реализовать маленькую фичу через агента.
- Перед каждым шагом писать, что именно агент должен сделать.
- После каждого шага читать diff и просить объяснить изменения.
- Отклонить или переделать правку, если агент вышел за рамки задачи.
