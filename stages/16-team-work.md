# Этап 16. Командная работа и production-подход

[← К roadmap](../README.md)

Цель: сделать deepcoding нормальной инженерной практикой команды.

## Что нужно команде

- Общие правила AI-разработки.
- Список разрешенных инструментов.
- Политика по данным и секретам.
- Единые prompts для review, tests, docs.
- Обязательные проверки перед PR.
- Обновляемая документация.
- Метрики: скорость, дефекты, качество PR, время review.

## Definition of Done для AI-задачи

- Код понятен разработчику.
- Diff минимальный.
- Тесты добавлены или причина отсутствия объяснена.
- Линтер/форматтер пройдены.
- Нет секретов.
- Риски описаны.
- Документация обновлена, если нужно.
- Изменение прошло human review.
