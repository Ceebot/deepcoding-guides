# Этап 6. Планирование задачи

[← К roadmap](../README.md)

Цель: перестать сразу просить код и начать управлять работой через план.

## Когда нужен план

- Новая фича.
- Рефакторинг.
- Неясные требования.
- Изменения в нескольких файлах.
- Работа с данными, миграциями, оплатой, безопасностью.

## Два способа получить план

### 1. Явно попросить план в промпте

```md
Изучи задачу и проект.
Не меняй файлы.
Составь план:
1. Что нужно проверить.
2. Какие файлы будут затронуты.
3. Какие риски есть.
4. Какие тесты нужны.
5. Какой самый маленький первый шаг.
```

### 2. Переключиться в режим планирования

Во многих агентских средах есть отдельный режим планирования: Cursor, Claude Code, Codex и другие.

В этом режиме агент обычно:

- изучает проект без изменения файлов;
- задает уточняющие вопросы перед реализацией (если есть непонятные моменты в задаче);
- предлагает итоговый план;
- ждет подтверждения перед кодом.

План можно вместе с агентом отредактировать: убрать лишнее, поменять порядок шагов, уточнить тесты и риски. После этого можно дать план на исполнение.

## Перед планом можно обсудить задачу

Не обязательно сразу просить итоговый план. Сначала можно пообщаться с агентом о задаче: объяснить контекст, ограничения, спорные места и ожидаемый результат.

В Cursor для этого удобно использовать режим Ask: агент отвечает и помогает разобраться, но не меняет файлы (для других агентов тоже можно явно попросить обсудить задачу и не менять код, хотя в большинстве случаев агенты сами это понимают). Для более точного понимания задачи можно использовать навык `brainstorming` (например, из плагина superpowers).

Про skills и их подключение будут отдельные следующие этапы.

## Рабочая схема

1. Разведка: агент ищет похожий код.
2. Вопросы: агент уточняет спорные моменты.
3. План: агент предлагает шаги.
4. Подтверждение: разработчик правит план.
5. Реализация: агент реализует план.
6. Проверка: тесты, линт, ручной сценарий.

## Домашнее задание

- Пообщаться с агентом о задаче: объяснить контекст, ограничения, спорные места и ожидаемый результат.
- Попросить ИИ составить план в режиме планирования либо вручную, указав путь, куда сохранить план.
- Самостоятельно удалить лишние шаги из плана.
- Дать агенту выполнить план.
- Проверить результат.
