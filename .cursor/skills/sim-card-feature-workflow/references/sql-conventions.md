# Соглашения по бизнес-SQL-проверкам (project/)

Этот файл агент читает **по надобности** — когда реально пишет SQL. В SKILL.md держим
только ссылку на него, чтобы не раздувать постоянный контекст.

- Один сценарий — один читаемый `SELECT`.
- Первой строкой комментарий: что проверяем простыми словами.
- Имена таблиц и колонок сверять с `.cursor/skills/db-schema/SKILL.md`, не выдумывать.
- Статусы и enum брать только из схемы (CHECK-ограничения), не угадывать.
- «Активная услуга» — это `sim_card_services.status = 'active'`, а не догадка по датам.
- Результат проверки должен быть воспроизводим после `make db-clean db-seed`.
