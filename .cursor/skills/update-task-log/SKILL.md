# Update Task Log

Цель: не забывать журнал изменений после работы агента.

## Когда применять

- изменился любой файл внутри `project/`;
- добавлена миграция;
- обновлен seed;
- изменены команды запуска или проверки.

## Что делать

1. Открыть `task_logs.md`.
2. Найти блок текущей даты `YYYY-MM-DD`.
3. Если блока нет, создать его в начале файла.
4. Добавить один короткий пункт.
5. Не перечислять все файлы, если смысл понятен одной фразой.

## Формат

```md
## 2026-06-15

- Добавлена миграция для eSIM и обновлен seed с тестовыми картами.
```

## Чего не делать

- Не писать длинный отчет.
- Не добавлять блок "Файлы".
- Не логировать правки документации для ИИ.
