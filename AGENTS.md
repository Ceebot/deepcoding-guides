# AGENTS.md

## О проекте

Этот репозиторий - учебный гайд по deepcoding: осмысленной разработке с ИИ, где программист использует AI-инструменты для ускорения работы, но сохраняет контроль над архитектурой, качеством, безопасностью и итоговым кодом.

Основной вход в курс: [README.md](README.md).

## Смысл проекта

Проект должен помогать новичкам и практикующим разработчикам перейти от хаотичного "вайбкодинга" к управляемой работе с ИИ:

- правильно ставить задачи агентам;
- давать нужный контекст без мусора;
- планировать перед реализацией;
- проверять AI-generated код тестами, ревью и линтерами;
- использовать правила, skills, MCP, субагентов и автономные workflow;
- строить безопасную AI-инфраструктуру для команды.

## Как работать с материалами

- `README.md` - краткий roadmap и ссылки на этапы курса.
- `stages/*.md` - отдельные уроки курса.
- `notes.md` - исходные заметки и идеи, не финальная структура.

## Правила для AI-агентов

- Пиши просто, без лишней академичности.
- Сохраняй формат Markdown.
- Не раздувай текст, если можно объяснить короче.
- При добавлении нового урока создавай отдельный файл в `stages/` и добавляй ссылку в `README.md`.
- Не удаляй `notes.md`: это источник идей.
- Тестовый проект для демонстрации работы агентов находится в `project/`.
- Разработка тестового проекта должна происходить строго внутри директории `project/`.
- При разработке тестового проекта ориентируйся на ТЗ: `project/telecom-sim-cards-spec.md`.
